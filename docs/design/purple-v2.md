# 紫色品牌与操作体验第二版

用户已在当前会话确认：以紫色为品牌主色，保证业务功能完整性与操作便捷；安装并使用 frontend-design。
技能来源：anthropics/skills，skills/frontend-design，ca45fc496a3436251f191354091d557da31c15b5。

## 设计目标与约束

面向留学顾问、签证专员、财务与管理人员，让人从待办进入具体学生的下一步办理动作。
保留26个源码模块、5类补充场景、所有业务页签、路由和已有业务条件。原型仍为虚构数据与内存操作。
仅操作原型仓库和releases产物；保留第一版；不修改CRM生产业务源码、配置、数据或服务。

## 视觉系统

核心色：品牌紫 #6D3CCF；深紫 #412478；浅紫 #F2ECFC；画布 #F7F7FB；白 #FFFFFF；正文 #252139。
状态：成功绿、待办琥珀、逾期红独立表达；不把全部状态改为紫色。
字体：Avenir Next配合PingFang SC，数字使用等宽数位；正文14–15px，常用辅助文字至少12px；主操作高44px。
布局：固定的紫色品牌导航；右侧白色业务画布；待办为首页主区域；列表与操作使用统一对齐线。
风格重点只放在导航与办理定位，不使用装饰渐变、满屏紫卡片或重复英文眉题。

## 对设计计划的复核

保留任务工作台是留学服务的办理需要，而非营销式大数字首页。降低重复卡片装饰，以一个紫色导航区建立品牌；业务区保持白色。页签分组服务学生多周期和后续服务，不删减功能。
